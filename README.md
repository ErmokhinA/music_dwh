# Music Tracks Data Warehouse

Лабораторные работы по дисциплинам:
- «Высокопроизводительная обработка и анализ данных»
- «Администрирование больших данных»

## Описание проекта

Хранилище данных для предметной области музыкальных композиций.
Реализована многослойная архитектура:

CSV → Source → STAGING → ODS → DWH (схема «снежинка»)

## Структура проекта

- app.py — Streamlit-приложение: анализ данных и загрузка в хранилище
- db_utils.py — создание базы данных и всех таблиц
- load_source.py — загрузка CSV в таблицу-источник
- staging.py — перенос Source → STAGING (без параметров, as is)
- ods.py — очистка и инкрементальная загрузка STAGING → ODS (параметры p_sdt, p_edt)
- dwh.py — загрузка ODS → DWH по схеме «снежинка»
- music_project.csv — исходные данные

## Схема «снежинка»

Факт: fact_listening

Измерения: dim_user, dim_track, dim_artist, dim_genre, dim_city, dim_date, dim_time, dim_day

## Правила очистки данных

- Пустой Track — удаление записи
- Пустой artist — замена на Unknown Artist
- Пустой genre — замена на unknown
- Пустой City — замена на Unknown
- Полные дубликаты — оставить одну запись
- Разный регистр жанра — приведение к нижнему регистру
- Неверный формат времени — удаление записи

## Запуск

Установить библиотеки:

pip install streamlit pandas matplotlib

Запустить приложение:

python -m streamlit run app.py

Приложение откроется по адресу http://localhost:8501
